# DrawTabResearch

Research on drawing tablets, pen displays, drivers, and related software. Each investigation records the method, findings, and supporting data.

## Investigations

- [Tablet Driver Install Footprint](investigations/tablet-driver-install-footprint/README.md) covers sampled Windows, macOS, and Linux installers. It includes file fingerprints, package and filesystem evidence, and an analysis of installing drivers from multiple brands. The published findings distinguish static inspection from questions that still need live testing.
