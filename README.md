# DrawTabResearch

Research on drawing tablets, pen displays, drivers, and related software. Each investigation records the method, findings, and supporting data.

## Investigations

- [Tablet driver filesystem investigation](investigations/tablet-driver-filesystem/README.md) covers sampled Windows, macOS, and Linux installers. It includes file fingerprints, package and filesystem evidence, and an analysis of installing drivers from multiple brands. The published findings distinguish static inspection from questions that still need live testing.

Tablet specifications and structured reference data are maintained in [DrawTabData](https://github.com/TheSevenPens/DrawTabData).
